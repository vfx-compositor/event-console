# AI 도구·모델 사용 기록

이 프로젝트는 제작자의 기획과 팀 내 시뮬레이션 피드백을 바탕으로 여러 AI 도구·모델과 함께 개발했습니다. 개발뿐 아니라 코드 검토, 조사, 문서 작성과 배포 준비도 아래 확인 범위에 포함합니다.

Claude Code, Codex, Hermes는 작업을 실행하는 도구입니다. 모델은 그 안에서 실제 응답을 생성하거나 대화 압축 같은 보조 작업을 맡습니다. 예를 들어 Hermes에서 GPT 계열 모델을 사용할 수 있으므로 도구명과 모델명을 같은 항목으로 합치지 않습니다.

## 행사 전체 기록에 함께 나타난 모델

`claude-fable-5-1`, `claude-haiku-4-5-20251001`, `gpt-5.5`, `gpt-5.6-terra`도 관련 행사 프로젝트 로그에서 확인했습니다. 해당 기록에는 프레젠테이션·스토리보드·기타 행사 작업이 섞여 있어 현재는 콘솔 기여 모델로 확정하지 않았습니다. 후속 확인이 되면 위 표에 역할과 범위를 추가할 수 있습니다.

## 토큰 사용량 부분 집계 결과

**남아 있는 로컬 로그에 대한 부분 집계는 수행했습니다. 전체 콘솔 개발 토큰 총량은 미확정입니다.** 아래는 2026년 9월 6일에 저장한 집계 결과이며, 실시간으로 갱신되는 카운터가 아닙니다. Claude Code와 Codex는 같은 날 **15:24 KST(06:24 UTC)**를 집계 종료 시점으로 고정했습니다. 이후 작업은 이 수치에 포함되지 않습니다.

| 도구 | 집계한 기록 범위 | 캐시 읽기 제외 | 캐시 읽기 | 캐시 포함 처리량 | 해석 |
| --- | --- | ---: | ---: | ---: | --- |
| Claude Code | 콘솔 전용 프로젝트 또는 콘솔 작업 경로가 확인된 응답 1,387개 | 9,740,356 | 239,048,537 | 248,788,893 | 동일 조건으로 재현한 부분 집계 |
| Codex | 1차 분류에서 콘솔 경로 근거가 있는 턴으로 묶은 요청 1,862개 | 6,637,893 | 222,068,480 | 228,706,373 | **귀속 분류가 잠정적인 후보 집계** |
| Hermes | 콘솔 중심 부모·자식 2세션, 보조 역할 포함 341호출 | 4,887,894 | 53,756,672 | 58,644,566 | 세션 단위 부분 집계 |

‘캐시 읽기 제외’는 비캐시 입력·출력과 기록된 캐시 생성 입력의 합계입니다. 새로 작성된 코드나 응답의 길이만을 뜻하지 않습니다. **세 행을 합산해 총 개발 토큰이나 비용으로 제시하지 않습니다.** 도구별 기록 단위와 작업 귀속 기준이 다르고, 조사·검토·문서·배포 준비도 섞여 있습니다.

### 아직 총량을 확정하지 못한 이유

- **Claude Code:** 혼합 행사 로그까지 도구 입력의 경로 신호로 넓히면 캐시 포함 약 9.16억~9.45억 토큰이 후보로 잡힙니다. 하지만 인용된 경로나 서로 다른 도구 입력의 신호가 함께 잡힐 수 있어 탐색용 추정치로만 남겼습니다. 위 표에는 이 확대분을 넣지 않았습니다.
- **Codex:** 누적 카운터를 매번 더하지 않고 요청별 사용량으로 정규화했습니다. 이후 직접 작업 경로와 단순 언급을 구분해 재검토했지만, 중첩된 JavaScript·셸 실행의 실제 경로를 충분히 해석하지 못해 직접 작업을 누락할 수 있었습니다. 후속 분류는 1차 집계를 확정하거나 대체할 수준이 아니므로 위 수치도 콘솔 전용 확정값으로 보지 않습니다.
- **Hermes:** 위 두 세션 외에 남은 9세션의 323,901,008토큰은 다른 행사 작업과 섞여 있습니다. 메시지별 사용량으로 나눌 근거가 부족해 추가 귀속하지 않았습니다. 콘솔 중심 세션에도 메인 응답 외 압축·검토·승인·제목 생성 호출이 포함됩니다.
- **공통:** 삭제되거나 남아 있지 않은 로그와 집계 이후 작업은 반영할 수 없습니다. 기존에 함께 사용한 문맥도 캐시 처리량에 포함되므로, 요청이 콘솔 작업이라는 사실만으로 모든 입력 토큰이 콘솔 코드에만 해당한다고 볼 수는 없습니다.

## 토큰 사용량을 기록하는 기준

추가 기록에는 다음 항목을 함께 남깁니다.

| 항목 | 기록할 내용 |
| --- | --- |
| 집계 범위 | 콘솔 개발, 검토, 문서, 배포 준비, 기타 행사 작업 중 포함한 범위 |
| 기준 시점 | 집계 종료 시점과 확인 가능한 로그 기간 |
| 도구·모델 | 도구명과 로그의 모델 표기를 각각 기록 |
| 사용량 | 비캐시 입력, 출력, 캐시 생성, 캐시 읽기를 구분 |
| 중복 제거 | 스트리밍 반복, 누적 카운터, 포크 이전 이력, 부모·자식·보조 역할 처리 방식 |
| 한계 | 삭제된 기록, 분류가 어려운 혼합 작업, 아직 대조하지 못한 기록 |

캐시 읽기는 이전 문맥을 다시 활용한 처리량입니다. 출력 토큰과 같은 의미가 아니며, 같은 문맥이 여러 요청에서 재사용되면 매번 누적될 수 있습니다. 추론 토큰이 출력에 포함되는 도구에서는 이를 다시 합산하지 않습니다. 토큰 수와 실제 결제 금액 역시 구분합니다.

원본 대화, 개인 경로, 세션·요청 식별자와 계정 정보는 이 문서에 넣지 않습니다. 세부 집계 자료는 별도로 보관하고, 공개 문서에는 모델 표기·역할과 집계 결과·기준·확인 한계를 남깁니다.
